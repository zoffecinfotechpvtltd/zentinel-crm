Install
Three steps, no configuration
1

Download the installer

Get Zoffec Sentinel Setup.exe from the latest release.

2

Run it

Windows SmartScreen will flag it as unsigned — click More info → Run anyway. Choose your install location if you want somewhere other than the default.

3

Create your admin account

First launch asks you to set up the admin account — no default login ships with the app. From there, add your team under Users.
